# The method

A repeatable way to map any university's research landscape so that an undergraduate can decide
where to spend four years — and to do it without either flattering the institution or pretending
to more certainty than the evidence supports.

The UF work in `docs/` and `site/` is one worked example. This folder is the part that transfers.

## The method in one paragraph

Rank research areas on **two axes, not one**: how good the work genuinely is, and how hard it is
for an undergraduate to get inside. Rankings give you the first; nobody publishes the second, and
the second is what decides whether a student benefits. Then render the **evidence strength in the
artefact itself** — solid for documented, dashed for inferred, hollow for absent — so a reader can
see which claims you would defend. Treat **absences as findings**, because no institution will
ever publish what it lacks.

## What this method is not for

- **Choosing a university.** It assumes you are already somewhere, or already decided.
- **Ranking institutions against each other.** It is single-institution depth, which is a different
  genre from cross-institutional breadth. Do not average it into a league table.
- **Evaluating teaching.** Nothing here measures whether a professor is good to learn from. That
  requires talking to their students, which no index substitutes for.

## The test that matters

Not whether the map is comprehensive, and not whether it is novel. **Whether a second-year reads it
and does something different next week.** If the tiering is right and the access column is wrong,
it fails — they will target something excellent they cannot get into.
